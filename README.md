# URLmonster PRO

Высокопроизводительный парсер URL/логинов для Windows.

Один EXE-файл — никаких зависимостей, Python не требуется.

---

## Быстрый старт

1. Скачайте `URLmonster.exe`
2. Положите рядом `queries.txt` (список запросов)
3. Запустите `URLmonster.exe` — откроется GUI

### CLI (из командной строки)

```
URLmonster.exe --base "C:\data\base.txt" --out results
```

---

## Файлы в дистрибутиве

| Файл | Назначение |
|------|-----------|
| `URLmonster.exe` | Готовый к запуску EXE (64-bit) |
| `queries.txt` | Список запросов с группами |
| `rust_scan.pyd` | Rust-ядро для высокой скорости |

При работе программа создаёт рядом с собой:
- `settings.json` — сохранённые настройки GUI
- `presets.json` — пресеты конфигураций
- `unique_strings.bin` — БД уникальных строк для дедупликации между запусками

---

## Запросы (`queries.txt`)

Список запросов, один на строку. Поддерживаются группы и префиксы:

```
[Credentials]
login:email
full:password

[URLs]
full:https://example.com
site.com
```

### Префиксы

| Префикс | Что сохраняется |
|---------|----------------|
| `full:` | Полная строка с `https://` |
| `login:` | Только логин (первая часть) |
| *(нет)* | По настройке «Сохранять строку целиком» |

## Интерфейс

### Левая панель (настройки)

| Элемент | Описание |
|---------|----------|
| **Пресеты** | Выбор/сохранение/удаление конфигураций |
| **Язык** | RU / EN |
| **Источник** | Файл или папка ввода |
| **Папка результатов** | Куда сохранять результаты |
| **Запросы** | Количество, кнопка «Ред.», выбор группы |
| **Blacklist** | Исключающие фразы |
| **Режим** | Auto / Default / URL / Exact / Domain |
| **Фильтры** | Исключать пустые, Учитывать регистр |
| **Опции** | Мультипроцесс, Докачка, Regex |
| **Разделитель** | Авто / 20+ вариантов |
| **Разбить файлы** | По сколько строк делить результат |
| **Тема** | 16 цветовых схем |
| **Производительность** | Auto / SSD / HDD / NVMe |

### Правая панель (лог)

Цветовые теги сообщений: `[+]` (зелёный), `[!]` (красный), `[ok]` (бирюзовый).

При автоопределении в логе пишется какой разделитель и режим выбран для каждого файла.

### Нижняя панель

| Кнопка | Действие |
|--------|----------|
| **Start** | Запуск сканирования |
| **Stop** | Остановка с сохранением результатов |
| **Watch** | Режим наблюдения — автоскан новых файлов |
| **Results** | Просмотр результатов скана |
| **Web UI** | Встроенный веб-интерфейс (порт 8765) |
| **Tray** | Свернуть в системный трей |

### History

Вкладка History показывает список прошлых запусков — дату, время, количество найденных строк. Можно открыть результат в проводнике.

## Режимы сканирования

| Режим | Описание |
|-------|----------|
| **Auto** | Автоопределение формата по первым 30 строкам |
| **Default** | Делит по разделителю, парсит login:password |
| **URL** | Добавляет `https://` если нет протокола |
| **Exact** | Требует ровно 2 части через разделитель |
| **Domain** | Нормализует запрос до домена |

## Универсальный парсер разделителей

Программа поддерживает **50+ типов разделителей**. Разделители между полями могут быть одинаковыми или разными.

### Схема парсинга

```
URL <sep1> Login <sep2> Password
```

### Поддерживаемые разделители

| Категория | Примеры |
|-----------|---------|
| Одиночные | `:` `;` `\|` `/` `\` `.` `-` `_` `~` `#` `@` `!` `$` `%` `^` `&` `*` `+` `=` |
| Пробелы | TAB, пробел, 2 пробела, 3 пробела |
| Многосимвольные | `::` `\|\|` `---` `###` `<sep>` `->` `=>` `:::` |
| URL-encoded | `%3A` (двоеточие) `%7C` (пайп) `%20` (пробел) |
| Смешанные | `::\|` `: ;` `; :` ` : ` (пробел вокруг) |
| Повторяющиеся | `....` `;;;;` `====` `~~~~` `----` |

### Примеры строк

```
https://site.com::user::pass
https://site.com -> user -> pass
https://site.com%3Auser%3Apass
user;pass
user:pass:url
```

### CLI-опции для разделителя

```
--delim auto        Автоопределение (по умолчанию)
--delim colon       Двоеточие
--delim pipe        Пайп
--delim tab         Табуляция
--delim semicolon   Точка с запятой
--delim comma       Запятая
--delim slash       Слеш
--delim backslash   Обратный слеш
--delim dot         Точка
--delim dash        Тире
--delim underscore  Подчёркивание
--delim tilde       Тильда
--delim hash        Решётка
--delim at          Собака
--delim exclaim     Восклицательный
--delim dollar      Доллар
--delim percent     Процент
--delim caret       Циркумфлекс
--delim amp         Амперсанд
--delim star        Звёздочка
--delim plus        Плюс
--delim equals      Равно
--delim login       login:password
--delim password    password:login
```

## Движки поиска

Порядок приоритета (чем выше, тем быстрее):

1. **Rust** — весь блок за один C-вызов (встроено в .pyd)
2. **Aho-Corasick** — один проход по строке, автомат для всех запросов
3. **Regex** — регулярные выражения
4. **Case-sensitive** — прямой поиск подстроки
5. **Default** — регистронезависимый поиск

## Дедупликация

**Cross-file:** Дубли между temp-файлами разных воркеров убираются в памяти.

**Cross-run:** Хеши (MD5, первые 8 байт) сохраняются в `unique_strings.bin`. Строки, уже бывшие в предыдущих запусках, пропускаются.

---

## Отчёты

В папку запуска `results/YYYY-MM-DD_HH-MM-SS/` создаётся:

- `report.txt` — текстовый отчёт
- `report.html` — HTML с таблицами + график Chart.js (топ-10 доменов)
- `report.json` — структурированные данные
- `{запрос}.txt` — найденные строки по каждому запросу

---

## Докачка (Resume)

При включённой опции «Докачка» программа отслеживает:
- Какие файлы обработаны
- Сколько данных обработано

**Важно:** Если файлы не изменились, повторный запуск с докачкой пропустит их. Для полного перескана выключите «Докачка» или удалите `processed_files.json`.

## CLI — все аргументы

```
--base FILE        Источник (файл/папка)
--out DIR          Папка результатов
--queries Q        Файл запросов или список через запятую
--mode MODE        auto / default / url / exact / domain
--delim D          auto / colon / pipe / tab / semicolon / ...
--regex            Включить regex
--blacklist B      Исключающие фразы через запятую
--split N          Разделять результат по N строк
--workers N        Число воркеров
--no-multiprocess  Отключить мультипроцесс
--resume           Режим докачки
--save-full        Сохранять полную строку
--no-unique-db     Отключить БД уникальных строк
--dry-run          Тестовый запуск (без сохранения)
```

## Производительность

- **Worker count** зависит от типа диска: HDD=2, SSD=4, NVMe=4
- **Chunk size** от 1 MB до 2 GB
- **Buffer** чтения 16 MB, записи 4 MB
- **Rust-ядро** — до 4 GB/мин на SSD
- **Hang detection** — 120 сек без прогресса -> terminate
